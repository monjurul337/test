FIREBASE CONSOLE — MUST DO (nahole login cholbe na)
Project: r-final-f0c62
====================================================================

STEP 1 — Sign-in methods ON korun
  console.firebase.google.com > project "r-final-f0c62" >
  Build > Authentication > Sign-in method:
  [x] Email/Password -> Enable kore Save
  [x] Google         -> Enable kore support email select kore Save

  Eta na korle error: "operation-not-allowed"

STEP 2 — (Optional, pore) Realtime Database rules
  v52 te profile RTDB te save hoy NA (shudhu Auth). Tai
  Database rules v52 er jonno dorkar nai.

STEP 3 — Google login er jonno (EMAIL LOGIN ER JONNO NA)
  Email + password login uporer Step 1 dilei cholbe,
  google-services.json charai.
  Google button er jonno aro 2 ta jinish lagbe:
  a) Firebase Console > Project Settings > "Your apps" >
     Android app add korun:
     - Android package name: com.geminihd.studio
     - App nickname: Zedge Studio
     - Download google-services.json
     - File ta repo te android/app/google-services.json
       hisebe bosate hobe (porer version e), ba amake pathate
       hobe — ami bosiye dibo.
  b) SHA-1 add korun:
     - Project Settings > Android app > SHA certificate
       fingerprints > Add fingerprint
     - Debug APK er SHA-1 lagbe. Terminal e:
       keytool -list -v -keystore ~/.android/debug.keystore
       -alias androiddebugkey -storepass android -keypass android
       (output er SHA1 line ta copy korun)
     - SHA-1 na dile Google login "ApiException: 10" error dibe.
       App e tokhon ei kotha tai Bangla te dekhabe.

COMMON ERRORS (app e Bangla te dekhabe)
--------------------------------------------------------------------
- "operation-not-allowed"   -> Step 1: method ta ON kora nai
- "email-already-in-use"    -> Ei email e account ache, Login korun
- "invalid-credential"      -> Email ba password vul
- "weak-password"           -> Password kompokkhe 6 character lagbe
- "ApiException: 10"        -> Step 3: google-services.json / SHA-1 baki
- "Login service start hoy nai" -> Internet nai ba Firebase
  config e problem; Retry tap korun

NOTE
--------------------------------------------------------------------
- Firebase config (apiKey/appId/...) lib/firebase_options.dart
  e ache — eta public client identifier, password na.
- Kono password app e save hoy na, sob Firebase Auth er
  maddhome hoy.

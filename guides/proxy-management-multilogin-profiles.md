# Proxy Management for Multilogin Profiles

Proxies are half of a believable **antidetect browser** setup. **Multilogin** profiles should map 1:1 to stable endpoints where possible.

## Proxy types

| Type | Use case |
|------|----------|
| Residential | Social, ads, strict platforms |
| Mobile | Apps mimicking phone networks |
| Datacenter | Only when platform allows; higher risk |

## Rules

- One default country per profile  
- Rotate only when your workflow requires it—avoid mid-session IP jumps  
- Store credentials securely; rotate leaks immediately  

## Competitors

**GoLogin**, **Kameleo**, and **AdsPower** also bind proxies; compare integration UX and bulk import if you manage 100+ endpoints.

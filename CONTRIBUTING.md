# Contributing

Thanks for helping improve the **Anti-Detect Browser** knowledge base by [@Anti-detect](https://github.com/Anti-detect).

## What we accept

- Factual corrections with sources (vendor docs, changelog links)
- New comparison guides following naming: `{competitor}-vs-multilogin-antidetect-browser.md`
- Translations under `docs/{locale}/`
- FAQ entries in `docs/ANTIDETECT-BROWSER-FAQ.md`

## Style

- Neutral, educational tone — no impersonation of Multilogin or competitors
- Include disclaimer: community-maintained, not official
- End guides with links to [INDEX](ANTI-DETECT-BROWSER-INDEX.md) and [FAQ](docs/ANTIDETECT-BROWSER-FAQ.md)
- Pricing CTAs use only: `https://multilogin.com/pricing/?utm_source=saas&utm_medium=partner&a_aid=saas&a_bid=f5fad549` and codes **SAAS50** / **MIN50**

## Pull request checklist

- [ ] Spell-check and readable headings (`##` structure)
- [ ] No third-party affiliate links except the official Multilogin URL above
- [ ] No scraped logos or trademark-heavy assets
- [ ] Updated `ANTI-DETECT-BROWSER-INDEX.md` if adding pages

## Issues

Use GitHub Issues for typos, broken links, or guide requests. Do not post promo spam.

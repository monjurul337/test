## What is an anti-detect browser?

An **anti-detect browser** (also **antidetect browser**) runs isolated **browser profiles** with separate cookies, cache, and **fingerprints** (canvas, WebGL, timezone, fonts). Teams use them for ads, marketplaces, and affiliate stacks when one normal browser cannot safely separate identities.

**Multilogin** is the benchmark name in this category; this repo documents how it compares to **GoLogin alternative**, **AdsPower alternative**, and other **multi-account browser** tools.

# Security Policy

This repository contains **documentation only** (Markdown). It does not ship application code or handle user credentials.

## Reporting documentation issues

- Broken or misleading links: open a [Fix report](https://github.com/Anti-detect/Multilogin-Mastery--Top-1-Anti-detect-browser/issues/new?template=fix-report.yml)
- Do not post proxy lists, account cookies, or API secrets in public issues

## Product security (Multilogin)

For vulnerabilities in the Multilogin product, contact **Multilogin** through their official security / support channels on [multilogin.com](https://multilogin.com).

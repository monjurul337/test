What it does

Everything a self-published title needs, produced in one pass.

Plan, then write

A book bible first - cast, setting, clues, the ending - then every chapter written against it plus a running summary, so chapter 14 never contradicts chapter 3.

Cover studio

AI-generated cover artwork at 1600 x 2560 - the image model draws the picture, the app typesets the title on top. Four options, or build your own with colour, layout and font pickers and a shuffle button. The choice goes straight into the EPUB.

Editor pass

The finished manuscript is read back for continuity slips, repetition, filler and pacing. You get a score, a verdict and a one-tap rewrite for each flagged chapter.

Publishing checklist

Price, BISAC, keywords, age rating, DRM, preview limits and dates - with the reason behind each one and a copy button. The same list writes metadata.txt.

Front & back matter

Copyright page, author bio, an "Also by" list and a polite review request, built into the book the way a paid title is expected to look.

Batch & bulk keys

One topic per line writes a whole queue of books. Paste a pile of API keys and the app rotates through them, parking any key that hits its rate limit.

How it works

Four steps, no account, no server.

  1. Paste your API keys - Google Gemini, NVIDIA, or both.
  2. Type a topic, pick fiction or non-fiction, set chapters and pages.
  3. Press Generate book and watch the log.
  4. Download the ZIP: EPUB, cover, upload sheet and plan.

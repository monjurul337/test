GITHUB SECRETS - Single account version - client er nijer value boshaben
==========================================
Repo -> Settings -> Secrets and variables -> Actions -> New repository secret
Niche er NAME hubohu ekoi rakhte hobe (boro hater okkhor). VALUE te shudhu URL/token, shesh e / ba space dibe na.

Ei bundle e account matro EKTA (slot name: ZEDGE1), kintu tar Firebase project holo:
  projectId:   zedge2-e8d78
  databaseURL: https://zedge2-e8d78-default-rtdb.firebaseio.com
Tai ZEDGE1_DB_URL secret e EI databaseURL tai boshate hobe.

---------- REQUIRED (ei gula na dile bot/gate cholbe na) ----------

TELEGRAM_BOT_TOKEN
  = @BotFather theke notun bot token (purono leak howa token revoke kore notun nin)

TELEGRAM_CHAT_ID
  = client er Telegram chat ID (@userinfobot theke)

ZEDGE1_DB_URL
  = https://zedge2-e8d78-default-rtdb.firebaseio.com

R2_WORKER_URL
  = https://<client-er-r2-worker>.workers.dev

---------- OPTIONAL (Zedge login workflow input e na dile ei gula use hobe) ----------

ZEDGE1_EMAIL     = zedge account er email
ZEDGE1_PASSWORD  = zedge account er password

---------- CHECK ----------
1. Secret dewar por Actions -> Zedge 1 -> Run workflow (force run) diye ekbar chalan.
2. Log e 'FIREBASE_DB_URL is not set' dekhle secret er NAME bhul ba missing.
3. Desktop app build (Build Desktop App workflow) er jonno kono secret lage na.

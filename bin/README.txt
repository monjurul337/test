This folder holds the WireGuard tunnel engine (wireproxy).

- GitHub Actions builds download wireproxy v1.1.3 into this folder
  automatically for Windows / macOS / Linux before packaging.
- For a local run: download wireproxy for your OS from
  https://github.com/windtf/wireproxy/releases
  and put the binary here as wireproxy (or wireproxy.exe on Windows),
  or just install it on your system PATH.

OpenVPN needs no file here — Moxixo uses your installed OpenVPN client.
